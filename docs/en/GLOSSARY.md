# Technical & Enterprise Glossary

| Term | Persian Equivalent | Technical Definition |
| :--- | :--- | :--- |
| **Canonical Data Model** | مدل داده کاننیکال | Vendor-independent standard schema normalizing data across heterogeneous ERP, CRM, and BPMS systems. |
| **Semantic Layer** | لایه معنایی شاخص‌ها | Governed repository of versioned, mathematical metric formulas owned by the CFO and COO. |
| **Subledger Reconciliation**| تطبیق زیرسیستم با دفترکل | Verification process validating that operational billing and inventory balances match double-entry GL ledgers. |
| **Read Replica (AlwaysOn)** | پایگاه داده کپی خواندنی | Dedicated read-only replica used for analytical querying without impacting OLTP operational performance. |
| **Change Data Capture (CDC)** | استخراج تغییرات داده | Database mechanism for tracking row-level mutations (`INSERT`, `UPDATE`, `DELETE`) with minimal overhead. |
| **OEE** | اثربخشی کلی تجهیزات | Comprehensive manufacturing productivity metric calculated as `Availability × Performance × Quality`. |
| **DSO** | دوره وصول مطالبات | Average number of days required to collect payment after sales invoices are confirmed. |
| **Tool Calling** | فراخوانی ابزار | Capability of an LLM to route structured intent to deterministic calculation tools rather than guessing figures. |
| **PII Data Masking** | ماسک داده‌های هویتی | Automated masking of National IDs, IBAN accounts, and phone numbers before LLM synthesis. |
| **Local Inference (vLLM)** | استنتاج محلی | Self-hosted LLM execution on internal enterprise GPU clusters ensuring zero data egress. |
| **VF (Verified Fact)** | حقیقت اعتبارسنجی‌شده | Highest evidence standard verified via working code, tests, and active database inspection. |
| **PNF** | شواهد عمومی یافت نشد | Public documentation not found (does not imply the vendor feature is absent). |
