# راهنمای اجرایی پیاده‌سازی صفر تا صد (Implementation Playbook)
## نقشه راه گام‌به‌گام استقرار پل هوش مصنوعی سازمانی و طرح آزمایشی ۱۲ هفته‌ای (PoC)

این راهنما برای آن نگارش شده است که یک کارخانه تولیدی یا هلدینگ بازرگانی در ایران بتواند بدون سردرگمی و بدون نیاز به استخدام مشاوران پرهزینه، پروژه هوش مصنوعی سازمانی را از نقطه صفر تا استقرار عملیاتی پیش ببرد.

---

## ۱. فازهای چهارده‌گانه استقرار (Phases 0 to 13)

```mermaid
flowchart LR
    P0["فاز ۰: کشف استراتژیک"] --> P1["فاز ۱: موجودی‌برداری"]
    P1 --> P2["فاز ۲: اثبات دسترسی"]
    P2 --> P3["فاز ۳: استخراج Read-Only"]
    P3 --> P4["فاز ۴: نگاشت کاننیکال"]
    P4 --> P5["فاز ۵: قراردادهای KPI"]
    P5 --> P6["فاز ۶: تطبیق مالی"]
    P6 --> P7["فاز ۷: داشبورد اجرایی"]
    P7 --> P8["فاز ۸: پرسش از داده (Ask)"]
    P8 --> P9["فاز ۹: تحلیل ریشه‌ای"]
    P9 --> P10["فاز ۱۰: مانیتورینگ انحرافات"]
    P10 --> P11["فاز ۱۱: پیش‌بینی نقدینگی"]
    P11 --> P12["فاز ۱۲: توصیه‌گری هوشمند"]
    P12 --> P13["فاز ۱۳: اقدامات تصویب‌شده"]
```

### فاز ۰: کشف استراتژیک و نیازسنجی مدیرعامل (Executive Discovery)
- **هدف:** شفاف‌سازی ۵ تا ۱۰ سؤال حیاتی روزانه مدیرعامل و هیئت‌مدیره.
- **خروجی:** سند اولیه بنچمارک سؤالات سازمان.
- **دروازه خروج (Exit Gate):** امضای فهرست ۱۰ سؤال توسط مدیرعامل.

### فاز ۱: موجودی‌برداری سیستم‌ها (System Inventory)
- **هدف:** شناسایی سیستم ERP مستقر (راهکاران، شماران، سپیدار، چارگون و ...)، نسخه‌ها و دیتابیس‌ها.
- **خروجی:** تکمیل جدول ماتریس سیستم‌های سازمان.

### فاز ۲: اثبات دسترسی ایمن به داده (Data-Access Proof)
- **هدف:** ایجاد کاربر پایگاه داده صرفاً خواندنی (`db_datareader`) یا راه‌اندازی AlwaysOn Read Replica.
- **خروجی:** اجرای موفقیت‌آمیز تست اتصال کانکتور (`testConnection()`).

### فاز ۳: استخراج غیرمخرب داده‌ها (Read-Only Extraction)
- **هدف:** استخراج اولین بسته داده‌ای جداول فاکتورهای فروش و طرف‌های تجاری با اعمال نرخ محدودیت (Rate Limiter).
- **دروازه خروج:** عدم مشاهده هرگونه کندی یا قفل‌شدگی در دیتابیس عملیاتی ERP.

### فاز ۴: نگاشت به مدل داده استاندارد (Canonical Mapping)
- **هدف:** تبدیل رکوردهای خام ERP به ساختار استاندارد `@ieab/canonical-model` همراه با ذخیره `sourcePk` و تاریخ شمسی.

### فاز ۵: تدوین و تصویب قراردادهای شاخص (KPI Contracts)
- **هدف:** تعریف دقیق فرمول فروش خالص، سود ناخالص و مطالبات معوق در لایه معنایی با امضای CFO.

### فاز ۶: آزمون تطبیق مالی و زیرسیستم‌ها (Reconciliation Gate)
- **هدف:** اجرای موتور `@ieab/metrics` و بررسی انطباق مجموع فاکتورهای فروش با مانده بستانکار سرفصل درآمدهای دفاتر کل دوبل.
- **شرط عبور:** اختلاف ریالی صفر یا زیر حد مجاز تعریف‌شده.

### فاز ۷ تا ۹: راه‌اندازی میز کار، پرسش و تحلیل ریشه‌ای
- استقرار وب‌اپلیکیشن اجرایی (`apps/executive-web`) و آزمایش پرسش‌های طبیعی مدیرعامل به زبان فارسی.

### فاز ۱۰ و ۱۱: پایش انحرافات و پیش‌بینی نقدینگی ۳۰ روزه
- فعال‌سازی الگوریتم‌های کشف استثنائات تجاری و پیش‌بینی کسری وجه نقد ناشی از تعهدات چک‌های صیادی.

## ۲. برنامه زمان‌بندی طرح آزمایشی دوازده‌هفته‌ای (12-Week PoC Plan)

| هفته | محورهای اجرایی | مسئول مستقیم | دستاورد ملموس |
| :---: | :--- | :---: | :--- |
| **۱** | شفاف‌سازی انتظارات مدیرعامل و تعریف ۱۰ سؤال کلیدی اولیه | مدیرعامل / مدیر پروژه | سند اهداف PoC |
| **۲** | راه‌اندازی سرور ایزوله و ساخت کاربر Read-Only روی دیتابیس کپی | مدیر دیتابیس (DBA) / متخصص ERP | گواهی اتصال امن |
| **۳** | استقرار مونو‌ریپو و اتصال کانکتور `@ieab/connector-generic-mssql` | مهندس داده | استخراج اولیه ۱۰۰۰ رکورد |
| **۴** | نگاشت ماژول فروش به مدل کاننیکال (`Invoice`, `Customer`) | مهندس داده | اعتبارسنجی نگاشت |
| **۵** | جلسه رسمی تصویب فرمول‌های مالی فروش و سود با حضور CFO | مدیر مالی (CFO) | ثبت شاخص‌ها در لایه معنایی |
| **۶** | اجرای تست تطبیق دفاتر کل و رفع مغایرت‌های احتمالی حسابداری | مدیر مالی / مهندس داده | دریافت برچسب `RECONCILED` |
| **۷** | استقرار سرور محلی مدل زبانی (vLLM / Qwen 2.5 72B) بر سرور داخلی | مهندس AI / زیرساخت | تست ابزار فراخوانی محلی |
| **۸** | پیاده‌سازی ابزارهای فراخوانی شاخص‌ها (`get_metric`) | مهندس AI | اتصال هوش مصنوعی به داده |
| **۹** | استقرار رابط وب اجرایی مدیرعامل (`apps/executive-web`) | توسعه‌دهنده فرانت‌اند | راه‌اندازی میز کار تحت وب |
| **۱۰** | اجرای آزمایشی بنچمارک توسط مدیرعامل و دریافت بازخورد | مدیرعامل | ارزیابی دقت پاسخ‌ها |
| **۱۱** | اعمال اصلاحات، تنظیمات امنیتی، ماسک داده‌ها و قفل دسترسی‌ها | مدیر امنیت / مهندس داده | گزارش ممیزی نهایی |
| **۱۲** | ارائه نهایی به هیئت‌مدیره و تصمیم‌گیری برای ورود به فاز تولید صنعتی | مدیرعامل / کلیه ذی‌نفعان | تصمیم به گسترش به کل سازمان |
