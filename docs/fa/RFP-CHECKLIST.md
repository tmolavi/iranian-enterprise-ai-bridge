# چک‌لیست استعلام و راهنمای کارفرمایان ERP (RFP Master Checklist)
## راهنمای دوگانه: «ERP داریم؛ حالا چه کنیم؟» و «هنوز ERP نخریده‌ایم؛ چه بخواهیم؟»

این سند برای مدیران عامل، مدیران مالی، مدیران فناوری و کمیته‌های خرید نرم‌افزار سازمانی تدوین شده است تا از قفل شدن داده‌ها (Vendor Lock-in) و تحمیل هزینه‌های سنگین در آینده جلوگیری شود.

---

## بخش اول: ERP داریم؛ حالا چه کنیم؟ (We Already Own an ERP)

اگر سازمان یا کارخانه شما سال‌هاست از یک نرم‌افزار ERP (مانند راهکاران، شماران، دیدگاه چارگون، رایورز، سپیدار یا نرم‌افزارهای سفارشی) استفاده می‌کند، **هرگز به بهانه اتصال به هوش مصنوعی سیستم خود را تعویض نکنید!**

### گام‌های اجرایی سریع:
۱. **موجودی‌برداری ماژول‌ها:** مشخص کنید کدام ماژول‌ها (فروش، انبار، بهای تمام‌شده، تولید، خزانه‌داری) واقعاً فعال و دارای داده معتبر هستند.
۲. **شناسایی پایگاه داده و زیرساخت:** تعیین نوع دیتابیس (عمدتاً SQL Server) و محل سرورها (On-Prem یا Cloud).
۳. **اثبات دسترسی خواندنی (Read Replica):** از تیم IT یا DBA بخواهید یک کپی همگام خواندنی (AlwaysOn Read-Only Replica) ایجاد کند تا سرعت سیستم اصلی افت نکند.
۴. **استقرار پل IEAB:** با استفاده از کانکتور `@ieab/connector-generic-mssql` داده‌های فاکتورها و انبار را استخراج کنید.
۵. **تعریف شاخص‌ها با CFO:** فرمول‌های فروش و سود را در لایه معنایی وارد کرده و با دفاتر کل تطبیق دهید.
۶. **شروع با ۱۰ سؤال کلیدی مدیرعامل:** پرسش‌های روزانه مدیرعامل را فعال کنید.

## بخش دوم: هنوز ERP نخریده‌ایم؛ چه چیزی از فروشنده بخواهیم؟ (Buying a New ERP)

هنگام تدوین اسناد مناقصه (RFP) یا مذاکره با شرکت‌های تأمین‌کننده ERP، موارد زیر را به عنوان **شروط الزامی قرارداد** درج نمایید:

| ردیف | بند الزامی قرارداد استعلام (RFP Clause) | دلیل اهمیت فنی برای هوش مصنوعی و BI |
| :---: | :--- | :--- |
| **۱** | **مالکیت تام و بدون قید داده‌ها (Data Ownership):** سازمان مالک مطلق داده‌ها و حق دسترسی مستقیم خواندنی به دیتابیس است. | جلوگیری از انحصار فروشنده برای هر گزارش جدید |
| **۲** | **مستندات کامل ساختار جداول (Data Dictionary):** ارائه مستندات شفاف نام جداول، فیلدها و ارتباطات کلیدی. | سهولت در نگاشت به مدل‌های استاندارد داده |
| **۳** | **درگاه استاندارد REST API / Webhooks:** ارائه وب‌سرویس‌های برخط برای خواندن اسناد بدون هزینه لایسنس مازاد. | استخراج آنی تغییرات بدون فشار به دیتابیس |
| **۴** | **پشتیبانی از Read Replica و CDC:** تضمین سازگاری ساختار جداول با AlwaysOn Availability Groups و Change Data Capture. | استخراج سریع داده‌های حجیم کارخانجات بزرگ |
| **۵** | **محیط آزمایشی مجزا (Sandbox / Staging):** ارائه محیط تست و داده‌های پایلوت بدون هزینه لایسنس سرور جدید. | تست امن کانکتورها و سناریوهای هوش مصنوعی |
| **۶** | **امکان خروجی دسته‌جمعی استاندارد (Bulk Export):** امکان دانلود تمام داده‌ها در قالب استاندارد CSV / Parquet. | تضمین خروج از سیستم (Exit Strategy) در آینده |
| **۷** | **تطبیق ارقام زیرسیستم‌ها با دفاتر دوبل:** تعهد نرم‌افزار به انطباق همیشگی کاردکس انبار و فروش با حسابداری کل. | جلوگیری از تناقضات مالی در هوش مصنوعی |
