# ارزیابی، مقایسه و بنچمارک نرم‌افزارهای سازمانی ایران (ERP Benchmark 2026)

> **سلب مسئولیت و شفافیت روش‌شناسی:** این گزارش بر اساس پژوهش‌های عمیق مهندسی داده در سال ۲۰۲۶ و استانداردهای شواهد تدوین شده است. هدف این گزارش رتبه‌بندی عامیانه تحت عنوان «بهترین ERP ایران» نیست، بلکه ارائه ماتریس‌های تصمیم‌گیری فنی و واقع‌بینانه متناسب با نوع سازمان و میزان دسترسی‌پذیری به داده‌ها (Data Accessibility) است.

## ۲. ماتریس دسترسی‌پذیری به داده‌ها (Data Accessibility Matrix)

مهم‌ترین معیار در اتصال هوش مصنوعی، میزان سهولت، ایمنی و هزینه دسترسی به داده‌های عملیاتی است:

| محصول | دسترسی به وب‌سرویس/API رسمی | دسترسی به Read Replica | امکان استقرار CDC | پیچیدگی ساختار جداول | نمره دسترسی‌پذیری (۱ تا ۱۰) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Generic SQL Server** | بله (بسته به معماری) | کاملاً پشتیبانی‌شده (AlwaysOn) | بله (SQL CDC / CT) | بسته به پیاده‌سازی | **۹ / ۱۰** |
| **Odoo بومی ایران** | بسیار عالی (JSON-RPC & REST) | بله (Postgres Streaming) | بله (Wal2Json) | مستند و شفاف | **۹.۵ / ۱۰** |
| **ERPNext بومی ایران** | بسیار عالی (REST API کامل) | بله (MariaDB Replica) | بله | مستند و استاندارد | **۹ / ۱۰** |
| **سپیدار** | خیر (دسترسی مستقیم دیتابیس) | بله | نیاز به فعال‌سازی | ساده و قابل تحلیل | **۷.۵ / ۱۰** |
| **راهکاران** | مشروط به لایسنس Web API | بله (AlwaysOn) | بله | تفصیلی شناور چندسطحی | **۶.۵ / ۱۰** |
| **دیدگاه چارگون** | بله (سرویس‌های SOAP / REST) | بله | متوسط | ساختار اختصاصی BPMS | **۷ / ۱۰** |
| **شماران سیستم** | عمدتاً از طریق دیتابیس/ویو | بله | بله | جداول تخصصی تولید | **۶.۵ / ۱۰** |

## ۳. ماتریس تصمیم‌گیری بر اساس نوع سازمان (Decision Matrices by Organization Type)

### الف) کارخانجات و صنایع تولیدی (Manufacturing & Heavy Industry)
- **اولویت اصلی:** ردیابی برخط مصرف مواد، درخت محصول (BOM)، کنترل توقفات ماشین‌آلات و OEE.
- **انتخاب‌های اول:** شماران سیستم (ShAuto)، راهکاران همکاران سیستم (ماژول بهای تمام‌شده و تولید)، Odoo صنعتی.
- **استراتژی هوش مصنوعی:** راه‌اندازی AlwaysOn Read Replica روی دیتابیس و اتصال شاخص‌های OEE و ضایعات به صورت قطعی.

### ب) هلدینگ‌ها و شرکت‌های چندرشته‌ای (Conglomerates & Holdings)
- **اولویت اصلی:** تجمیع داده‌های شرکت‌های تابعه، حسابداری تلفیقی و کنترل نقدینگی بین‌شرکتی.
- **انتخاب‌های اول:** راهکاران همکاران سیستم، رایورز، Odoo چندشرکتی (Multi-Company).
- **استراتژی هوش مصنوعی:** استفاده از مدل داده کاننیکال (`@ieab/canonical-model`) به عنوان لایه مشترک تجمیع داده‌های شرکت‌های تابعه با نرم‌افزارهای ناهمگن.

### ج) سازمان‌های خدماتی و دولتی (Services & Government)
- **اولویت اصلی:** مدیریت فرآیندها، اتوماسیون اداری بدون کاغذ، مصوبات و گردش نامه‌ها.
- **انتخاب‌های اول:** دیدگاه چارگون، رایورز، راهکاران اداری.
- **استراتژی هوش مصنوعی:** استفاده از بازیابی اسناد و مصوبات (RAG) برای پیگیری تکالیف هیئت‌مدیره و دستورالعمل‌ها.

### د) شرکت‌های چابک و سازمان‌های AI-First
- **اولویت اصلی:** باز بودن کامل APIها، مالکیت صددرصدی داده و امکان توسعه سریع میکرو‌سرویس‌ها.
- **انتخاب‌های اول:** Odoo، ERPNext یا دیتابیس‌های PostgreSQL/SQL Server با لایه معنایی مستقل.
