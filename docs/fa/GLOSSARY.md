# واژه‌نامه تخصصی هوش مصنوعی سازمانی و ERP (Glossary)

| اصطلاح انگلیسی | معادل فارسی | تعریف فنی و کاربرد در پل سازمانی |
| :--- | :--- | :--- |
| **Canonical Data Model** | مدل داده استاندارد / کاننیکال | ساختار داده‌ای استاندارد و مستقل از تأمین‌کننده که داده‌های نرم‌افزارهای مختلف را به یک زبان مشترک تبدیل می‌کند. |
| **Semantic Layer** | لایه معنایی شاخص‌ها | مخزن متمرکز و نسخه شده تعاریف ریاضی شاخص‌ها (KPIs) که توسط CFO و COO اداره و کنترل می‌شود. |
| **Subledger Reconciliation** | تطبیق زیرسیستم با دفترکل | فرآیند بررسی همخوانی ارقام فاکتورها و کاردکس انبار با اسناد ثبت‌شده در سرفصل‌های دوبل حسابداری. |
| **Read Replica (AlwaysOn)** | پایگاه داده کپی خواندنی | نمونه همگام‌سازی‌شده از دیتابیس اصلی که صرفاً برای استخراج گزارش‌ها استفاده می‌شود تا دیتابیس عملیاتی قفل نشود. |
| **Change Data Capture (CDC)** | ردیابی و استخراج تغییرات داده | فناوری پایگاه داده برای شناسایی و انتقال آنی ردیف‌هایی که درج، ویرایش یا حذف شده‌اند. |
| **OEE (Overall Equipment Effectiveness)** | اثربخشی کلی تجهیزات | شاخص استاندارد جهانی بهره‌وری خطوط تولید حاصل‌ضرب سه نرخ: در دسترس بودن، راندمان عملکرد و کیفیت. |
| **DSO (Days Sales Outstanding)** | دوره وصول مطالبات | متوسط تعداد روزهایی که طول می‌کشد تا وجه حاصل از فروش فاکتورها از مشتریان وصول شود. |
| **Tool Calling / Function Calling** | فراخوانی ساخت‌یافته ابزار | توانایی مدل زبانی در انتخاب ابزار محاسباتی قطعی به جای تولید و حدس زدن اعداد در متن. |
| **PII Data Masking** | ماسک اطلاعات هویتی محرمانه | پوشاندن خودکار کدملی، شماره شبا، شماره تلفن و حقوق پرسنل جهت جلوگیری از افشای داده‌های حساس. |
| **Local Inference (vLLM / Ollama)** | استنتاج محلی درون‌سازمانی | اجرای مدل‌های زبانی روی کارت‌های گرافیک و سرورهای داخلی بدون نیاز به اینترنت و بدون خروج داده از کشور. |
| **VF (Verified Fact)** | حقیقت اعتبارسنجی‌شده | بالاترین سطح شواهد در گزارش‌ها که با کد اجرایی و تست واقعی راستی‌آزمایی شده است. |
| **PNF (Public Evidence Not Found)** | عدم وجود شواهد عمومی | به این معنی که مستندات عمومی منتشر نشده است (به معنی عدم وجود ویژگی در نرم‌افزار نیست). |
